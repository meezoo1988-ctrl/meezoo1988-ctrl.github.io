# Mazen Hamdan Portfolio

Arabic personal portfolio with a complete English CV. Static HTML, CSS and JavaScript; no build step.

## Preview

Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000.

## GitHub Pages

Upload these files to `meezoo1988-ctrl/meezoo1988-ctrl.github.io` and select Settings → Pages → Deploy from a branch → main / root.

Includes responsive layouts, keyboard navigation, persistent light/dark theme, direct LinkedIn and WhatsApp links, and the original complete downloadable PDF CV.
